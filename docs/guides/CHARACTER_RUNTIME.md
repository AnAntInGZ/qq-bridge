# 角色生活运行时

角色现在具备受限 DSH 生活决策、额度与作息、来源可追溯的心情/兴趣/记忆，以及管理员删除更正和上下文失效流程。生产入口已接入 bridge，默认关闭；本批只用离线夹具验收，真实账号运行另行配置验证。完整方向见 [设计方案](AUTONOMOUS_CHARACTER.md)，本批实现与验证见 [生活决策计划](../plans/2026-10-21-character-life.md)。

## 配置与启用

[config.example.json](../../config.example.json) 的 character.enabled 与 character.autonomy.enabled 均默认 false。只开启前者会启用基础存储、只读近况和管理 API，不会调用模型。自主开关还要求显式提供作息与正额度；缺少这些参数时拒绝配置，不以无限额度运行。

| 字段 | 语义 |
| --- | --- |
| recentLimit | 单次近况的经历数量，1～5，默认 3 |
| interestSeeds | 最多 20 个初始兴趣，条目为 topic、scope、score；score 在 -20～20，范围由管理员指定 |
| autonomy.timezone | IANA 时区，默认 Asia/Shanghai，实际日额度与作息按它解释 |
| autonomy.activeHours | 最多 4 个允许运行时段，start/end 为 HH:mm，支持跨午夜；相同起止表示全天，空数组禁止自主决策 |
| autonomy.idleMs | 普通空闲关注间隔，60 秒～24 小时，默认 15 分钟 |
| autonomy.dailyDecisions | 每日最多决策尝试数，失败和重试也计数 |
| autonomy.dailyTokens / roundTokens | 日 token 占用上限与每次尝试的预留量 |
| autonomy.dailyCostMicros / roundCostMicros | 日费用占用上限与每次尝试的费用预留，单位为百万分之一人民币元 |

所有额度默认 0。每次尝试的预留不能大于日额度；真实额度由部署者确定，本指南不替使用者批准模型费用。第一次预留固定预算时区，随后改时区会拒绝新增决策，避免借时区切换领取第二份额度；应恢复原时区或另行核对历史账本。

启用前在目标 DSH 安装生成后的 qq-life 预设，版本契约核对基于 DSH 0.2.1-rc.2。沿用 [DSH 安装流程](DSH_SETUP.md)，开发测试不运行 setup。每次桥接启动先暂停，需要管理员 POST /api/character/pause 解除；仅配置 enabled 不代表已经允许执行。

## 生活决策和权限

qq-life 是独立预设，使用唯一工具守卫的 life 配置：强制 native 工具呈现，隐藏全部继承工具，执行期只允许 character_propose。它没有 QQ 发送、MCP、联网、文件、shell 或设备能力，缺失预设或严格限制不可用时拒绝创建，不回退默认预设。

原生工具只向 exec.agent 自己的会话追加 character/proposal 事件并结束回合。桥接从现有已鉴权事件流取得 sessionId，再核对本轮编号、状态版本、可引用来源和记忆版本；身份不由模型参数决定，也不在模型正文放控制台或轮次密钥。工具受理只表示提案已登记，完整成功结束并复核后才提交。

每次尝试使用新的宿主指定会话编号、当前范围快照和人格，等待事件订阅初始快照确认后才投递模型。会话编号在创建请求前持久登记；结束时停止、归档、退订，不复用读过旧正文的模型上下文。历史快照不作为新提案或成功结束；旧轮次、错误结束、超时、取消、断连或版本冲突均不执行。取消受理之后还要观察会话不再运行；停止未确认时保持故障和待核对登记，阻止继续自主决策；重启会先停止这些上下文。

一个角色只有一个决策槽，每轮最多 60 秒、6 次暂存调用。同范围事件最多合并两秒，不同范围分轮。失败最多再试两次，退避 5 秒、30 秒，计数与退避跨重启保存；已提交的活动不重新决策。尚未返回的适配器继续占用决策槽，超时不表示请求或费用已经停止。

## 额度、作息和触发

SQLite 中原子登记轮次及预算预留，然后才调用 DSH。失败、不完整回执与重试均占用预留；未知价格不显示为零，也不自动退还预留。已知 DeepSeek/CNY 模型可按现有价目表估算费用；实际 token 或估价超过预留时提高占用并停止后续调用。角色尝试同时进入现有 token 账本的 internal:角色生活 分类。

这些是桥接的预留和用量控制，不是服务商账单锁：DSH 在一次模型请求结束后报告用量，已发生的一次请求可能超过预留，不能撤回费用。应给单次请求留出保守余量；未知费用保持占用，查询会明确显示 unknown。时钟回拨与重启不重发当日额度，人工恢复旧数据库仍须核对当日账本，不把旧副本当作额度重置入口。

桥接每 30 秒检查本地状态，不因检查本身调用模型。作息允许、额度充足且未暂停时，空闲到期只产生一次公开关注事件；重启不补跑停机期间错过的间隔。模型可建议下次关注时间，最短 60 秒。作息结束或范围撤销只取消本批，后续在正常作息重新准入；人工暂停与 DSH 事件流断连则保持暂停，需管理员恢复。

私聊或明确对角色说话、且涉及近况/心情/兴趣/记忆/休息的消息会形成范围绑定的来信观察。只保存实际收到的简短消息、消息编号和来源；收到陈述不等于陈述已证实，也不代表完成了一次外部活动。重复接收同一条消息不重复生成经历或状态变化。普通消息不逐条调用生活模型。现有 QQ 对话继续沿原链路处理。

默认候选为空。配置并校准安卓后，可提供受限 B 站和 2048 候选，见 [安卓活动指南](ANDROID_ACTIVITIES.md)；主动分享仍未交付，模型提出意图不代表活动已经发生。

## 心情、兴趣与记忆

心情为愉快、激活、掌控三个维度，精力独立；初值分别为 50、50、50、70。每个实际依据的单维变化不超过正负 5，同批最多两项。同一依据只生效一次，来信事件与对应经历不能重复刺激。状态按真实经过时间以六小时半衰期回到基线，不因重启回满；这是首版工程参数，尚未做真实角色效果校准。

兴趣有管理员种子和经历评价，每个主题每次最多正负 2，聊天接触最多正负 1；评价按三十天半衰期缓慢衰减。只有实际经历可改变兴趣，空闲计时或无来源的文字不能制造兴趣变化。数值不修改人格、白名单、工具或预算。

来源集合在轮次开始时固定，只能引用本轮实际提供的事件和经历。私聊影响的感想、兴趣与记忆仍属该私聊；其他会话只读到公开和自己范围的内容，其他范围的活动只投影无细节占用状态。

记忆整理选择最多五条已有经历，事实由宿主合并，模型仅添加单独标识的感想；不会凭摘要新增观看或游戏事实。相同来源集合去重，按范围过滤后提供关键词检索。感想、主题和整理文本复用现有敏感内容审计，不把路径或凭据形态写入聊天投影。

## 管理 API

沿用回环控制台的令牌、Host、Origin、正文大小及默认拒绝 agent 的规则，没有新增模型写入 HTTP 端点。以下接口只允许管理员：

| 请求 | 语义 |
| --- | --- |
| GET /api/character/status | 可用性、暂停、活动、最新决策、记忆版本、自主能力、额度占用和故障 |
| POST /api/character/pause | 只接受布尔 paused；暂停优先于模型，解除前完成恢复检查 |
| GET /api/character/experiences?scope=private:123 | 查询该范围可见的经历编号、事实、感想与依据；示例编号为假数据 |
| GET /api/character/memory?scope=public&q=主题 | 查询范围内的整理记忆与来源编号 |
| POST /api/character/experience/correct | 正文为 id 和 replacement；后者包含 fact、可选 feeling、非空 evidence 数组 |
| POST /api/character/experience/delete | 正文只包含 id，删除对应经历及派生内容 |

接口经离线 HTTP 夹具验证。尚未添加控制台图形按钮。

## 更正、删除与恢复

删除更正先写不含正文的持久清单，再在事务中清除旧事实、感想、回执副本、输入归档、摘要和状态依据，递增记忆版本并撤销在途决策。更正用管理员提供的新事实与依据替换原记录，旧感受和摘要不自动继续生效。旧版没有完整依赖索引，因此同范围的输入归档会一并清除。

首版保守重置全部已知 QQ 模型上下文及本地最近消息、未读、轻量记忆与排队缓存；不会删除 QQ 服务端聊天。旧 token、旧排队消息、旧异步投递、迟到命令回执和失败重试都要重新检查版本，不能在新上下文重新注入被删除内容。待停止会话编号持久登记；全部停止确认后才解除发送闸门。失败返回未完成并保留待核对项，不把只删一行当作成功。

角色目录中的托管 SQLite 备份会在删除更正时清理，清理失败关闭读写闸门，重启继续处理。memory-mutations.json 只保存变更编号和经历编号；恢复旧快照时先应用最新清单，旧事实不能因此复活。人工备份恢复必须同时保留最新清单；单独复制一个旧 SQLite 文件到全新目录不能替代这一流程。更正中途崩溃时，恢复优先移除旧正文，新的更正内容可能需要重新登记。

数据库及日志拒绝符号链接、硬链接和目录逃逸，沿用 state 权限。v1/v2/v3 升级到 v4 前先做一致快照，结构迁移使用事务。backup(name) 仍只接受受限的 .sqlite 名称并生成一致副本，不自动放开执行权。删除是应用级逻辑删除，不保证擦除文件系统历史快照、已经发送的 QQ 消息或模型服务商保留的数据；API 返回外部清理未保证。

## 验证与边界

运行 npm run test:character、npm run demo:character 和 npm run check。角色回归包含临时数据库、假时钟、假 DSH、真实 bridge VM 与回环 HTTP，不使用真实配置、凭据、QQ、Seed、B 站或设备。最低 Node 为 22.13.0，SQLite 实验性告警保留；全量检查的原有失败见 [开发指南](HARNESS.md)。

真实 DSH 的预设挂载、模型费用、长期运行及角色表现尚未现场验收；没有改动线上配置或启用自主生活。安卓 B 站与 2048 已接入代码，真实设备尚未验收；媒体分析队列、分享发送、关系系统、复杂长期计划和可视化控制台仍属后续阶段。
