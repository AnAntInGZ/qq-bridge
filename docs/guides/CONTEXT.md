# 自主角色术语

本项目中的角色在 QQ 交流，并通过视频浏览和游戏积累经历。以下术语用于区分角色自身、交流窗口、实际活动和主观感受。

## 角色与交流

**角色**：具有连续身份、人格、兴趣、关系和经历的主体。同一角色可以出现在多个私聊或群聊中。
_避免混用_：QQ 账号、聊天会话、模型会话。

**人格**：角色相对稳定的身份设定、价值取向和表达习惯。短期情绪不直接改写人格。
_避免混用_：心情、当前提示词、长期记忆。

**会话**：角色与一个 QQ 私聊或群聊的交流范围，具有自己的消息上下文和信息可见边界。
_避免混用_：一个独立角色、全部生活记录。

**主体性**：角色能够依据自身状态、偏好、经历和环境选择行动，并决定是否参与交流。
_避免混用_：随机发言、持续调用模型、无限工具权限。

## 活动与依据

**意图**：角色希望做的事情及其原因，尚不代表操作已经发生。
_避免混用_：执行结果、完成记录。

**活动**：角色在一段时间内参与的一项具体事情，例如理解一个视频或进行一局游戏。
_避免混用_：一句“我在看视频”、一个尚未执行的计划。

**观察**：从内容来源或执行环境取得的信息，例如视频片段、棋盘画面或胜败提示。观察可能不完整，须保留来源与范围。
_避免混用_：模型推断、角色感想。

**执行回执**：执行方对一次操作实际进展或结果的确认。无法确认时，回执应表达结果未知。
_避免混用_：请求已受理、操作指令已发出、预计完成时间已到。

**经历**：角色确实接触或参与过的事件，保留发生时间、观察依据、执行结果及当时的感受。
_避免混用_：计划、编造的往事、对摘要的再次阅读。

**记忆**：角色从已有经历整理出的可回忆内容。记忆可以概括，但不能增加没有依据的事实。
_避免混用_：原始聊天记录、完整视频文件、模型隐藏推理。

**信息范围**：一项内容允许在哪些交流范围内被使用或表达。概括、检索和再次分享都不能扩大其原有范围。
_避免混用_：能读取就能外发、同一角色就能跨群公开。

## 状态与驱动

**心情**：受近期事件影响、随时间变化的主观状态，包括愉快程度、激活程度和对处境的掌控感。
_避免混用_：人格、精力、工具权限。

**精力**：角色承担活动和交流负荷的状态，影响活动时长与休息选择。
_避免混用_：情绪激动程度、模型计算资源。

**兴趣**：角色对主题和活动形成的相对稳定偏好，可以随实际接触和评价缓慢变化。
_避免混用_：某次推荐结果、单条群消息中的偏好要求。

**计划**：角色基于已有经历形成的未来安排，包含目标、由来和下一次关注时机。
_避免混用_：已完成活动、必须立即执行的系统指令。

**社交意愿**：角色在某个时刻、面对某个交流对象时，参与或主动分享的倾向。
_避免混用_：白名单权限、所有会话共用的强制回复概率。
