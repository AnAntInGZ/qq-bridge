# Linux 二代仿真部署

目标：将既有二代私聊能力部署到用户指定的 Linux 服务器，沿用已授权白名单和小鲸鱼人格。

1. 检查现有工作负载、资源与端口；保护已有应用。
2. 安装独立 Node 与固定版本 DSH，上传当前修复后的仓库文件；不迁入本机凭据或无关聊天数据。
3. 配置非 root 应用用户、受保护状态、回环管理端点与 systemd 服务。
4. 准备官方 SnowLuma 容器接入入口；由用户完成许可要求下的启动、协议确认与 QQ 登录。
5. 核对账号、受限预设和收发，再切换活动实例，避免两端同时回复。

当前环境：Debian 13 x86_64，内存约 2GB，已有业务应用与数据库。用户选择按现有 2GB 限额试运行。DSH 固定为本机已验证的 0.2.1-rc.2。既有 Windows 实例在远端验收前继续保留。
